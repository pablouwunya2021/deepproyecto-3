--------------------------------------------------------------------------------
 3. PROBAR LA API DESDE LA TERMINAL (con el servicio corriendo)
--------------------------------------------------------------------------------

# En otra terminal. Cambia LOCAL por $URL para probar la versión en producción.
export LOCAL=http://127.0.0.1:7860

curl -s $LOCAL/salud

curl -s -X POST $LOCAL/api/generar -H 'Content-Type: application/json' \
     -d '{"n": 4, "semilla": 2026}' \
  | python3 -c "import json,sys; d=json.load(sys.stdin); print(d['modelo'], d['latencia_ms'], 'ms'); [print(' ', p['nombre'], p['elemento'], p['rol'], p['semilla']) for p in d['personajes']]"

# Bajar un personaje exacto como PNG (cambia 12345 por una semilla de arriba)
curl -s "$LOCAL/api/personaje/12345.png?tam=512" -o personaje.png && open personaje.png

curl -s -X POST $LOCAL/api/retroalimentacion -H 'Content-Type: application/json' \
     -d '{"semilla": 12345, "modelo": "base", "voto": "me_sirve", "filtro": true}'

curl -s $LOCAL/api/estadisticas | python3 -m json.tool | head -40

--------------------------------------------------------------------------------
 8. CONSEGUIR USO REAL (pesa 20 puntos: "Evidencias del pase a producción")
--------------------------------------------------------------------------------

# Manda este link a personas AJENAS al equipo y pídeles que generen y voten:
echo "$URL/?n=8"

# Revisa cómo va el uso
open $URL/monitoreo

# Antes de la entrega (y antes de que el Space se reinicie, porque se borra
# la base de datos) exporta los registros:
curl -s "$URL/api/registros?limite=1000" | python3 -m json.tool > evidencias/registros/registros_produccion.json
curl -s "$URL/api/estadisticas" | python3 -m json.tool > evidencias/registros/estadisticas_produccion.json
curl -s "$URL/metrics" > evidencias/registros/metrics_produccion.txt

# Resumen rápido de lo exportado
python3 -c "import json; s=json.load(open('evidencias/registros/estadisticas_produccion.json')); v=sum(a['me_sirve']+a['descartar'] for a in s['retroalimentacion'].values()); print('generaciones', s['generaciones'], '| clientes distintos', s['clientes_distintos'], '| votos', v, '| p95', round(s['latencia_ms']['p95'] or 0), 'ms')"

# Cambia el marcador del README por el resumen real
python3 - <<'EOF'
import json
s = json.load(open("evidencias/registros/estadisticas_produccion.json"))
votos = {k: a["me_sirve"] + a["descartar"] for k, a in s["retroalimentacion"].items()}
ok = sum(a["me_sirve"] for a in s["retroalimentacion"].values())
tot = sum(votos.values())
txt = (f"ver `evidencias/registros/registros_produccion.json`: {s['generaciones']} generaciones, "
       f"{s['clientes_distintos']} clientes distintos, {tot} votos reales, aceptación "
       f"{(100 * ok / tot if tot else 0):.0f} %")
r = open("README.md").read().replace("PENDIENTE_REGISTROS_PRODUCCION", txt)
open("README.md", "w").write(r)
print(txt)
EOF

# OJO: NO corras la prueba de carga contra producción sin --sin-votos, porque
# mete votos simulados y ensucia los datos reales. Si quieres medir latencia real:
python3 scripts/prueba_carga.py --url $URL --solicitudes 40 --clientes 2 --sin-votos --salida evidencias/prueba_carga_produccion.json

 11. SI ALGO FALLA
--------------------------------------------------------------------------------

"Address already in use" al correr el servicio (el puerto 7860 está ocupado):
    lsof -ti :7860 | xargs kill

"Cannot connect to the Docker daemon":
    open -a Docker        # espera a que arranque y repite

"hf: command not found":
    pip install -U huggingface_hub     # y abre una terminal nueva
    # si sigue sin aparecer, inicia sesión así:
    python3 -c "from huggingface_hub import login; login()"

El Space dice "Sleeping" o tarda en abrir:
    Se duerme si nadie lo usa. Ábrelo y espera 1-2 minutos. Ábrelo 5 min antes de presentar.

El Space dice "Build error":
    open https://huggingface.co/spaces/$HF_USER/lumen?logs=build
    (manda el error para revisarlo)

El tablero de producción quedó vacío:
    El Space se reinició y se borró SQLite. Por eso hay que exportar (paso 8) seguido.

git push pide usuario/contraseña:
    GitHub ya no acepta contraseña: usa un token (Settings > Developer settings >
    Personal access tokens) o GitHub Desktop.
